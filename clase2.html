Clase 2

Instalación y Mantenimiento de Hardware y Software

Docente: Romano Andrés

Actividad de Diagnóstico

Responder las siguientes preguntas:

  1. ¿Por qué Windows se instala por defecto en la partición C?
  2. ¿Cuál es la diferencia entre una actualización de software y una actualización del sistema operativo?
  3. ¿Cuál es la diferencia entre FAT32 y NTFS?
  4. ¿Por qué debería particionar el disco duro de mi computadora?
  5. ¿Cómo accedo a la BIOS para cambiar el orden de arranque?
  6. Mencione los recursos y los pasos para preparar un pendrive booteable.

Respuestas

  1. Porque las particiones A y B estaban reservadas para las antiguas unidades de disquete.
  2. La actualización de software solo actualiza un programa específico, mientras que la actualización del sistema operativo mejora todo el sistema.
  3. FAT32 posee mayor compatibilidad; NTFS permite archivos más grandes, mayor seguridad y mejor rendimiento.
  4. Permite organizar la información, proteger archivos importantes e instalar distintos sistemas operativos.
    • Reiniciar la computadora.
    • Presionar la tecla correspondiente (Supr, F2, F10 o Esc).
    • Entrar al menú BIOS.
    • Buscar Boot o Boot Priority.
    • Seleccionar el USB o DVD como primer dispositivo.
    • Guardar los cambios con F10.
  6. Recursos:
    • Pendrive de 8 GB o más.
    • Archivo ISO.
    • Programa Rufus.
    Pasos:
    • Descargar la imagen ISO.
    • Conectar el pendrive.
    • Abrir Rufus.
    • Seleccionar la ISO.
    • Elegir el pendrive.
    • Iniciar el proceso.
    • Reiniciar la PC e iniciar desde el USB.

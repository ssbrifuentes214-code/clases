Clase 4

Diagrama del Funcionamiento Detallado de un Ordenador

Docente: Romano Andrés

1 Entrada de Datos

El usuario ingresa datos mediante dispositivos de entrada como teclado, mouse, escáner o micrófono.

La información es enviada al procesador para comenzar su procesamiento.

2 Procesador (CPU)

  • Recibe instrucciones del sistema operativo y los programas.
  • Ejecuta cálculos y operaciones.
  • Procesa toda la información.
  • Guarda temporalmente los resultados en la memoria RAM.

3 Memoria RAM

  • Almacena datos y programas temporalmente.
  • Solo funciona mientras la computadora está encendida.
  • Permite un acceso rápido a la información.

4 Disco Duro (HDD) o SSD

  • Almacena datos de forma permanente.
  • Guarda el sistema operativo.
  • Conserva programas y archivos.

5 Tarjeta Gráfica

  • Procesa imágenes y videos.
  • Recibe información del procesador.
  • Envía la imagen final al monitor.

6 Salida de Datos

  • Los resultados procesados se envían a los dispositivos de salida.
  • Ejemplos: monitor, impresora, parlantes o proyector.
  • El usuario puede visualizar o imprimir la información.

7 Sistema Operativo

  • Gestiona todos los recursos del ordenador.
  • Permite la comunicación entre el hardware y el usuario.
  • Coordina la ejecución de programas.
  • Controla el acceso a los dispositivos de hardware.

Conexiones del Sistema

  • Procesador → Memoria RAM: el procesador accede a los datos almacenados temporalmente en la RAM.
  • Memoria RAM → Disco duro (HDD) o SSD: carga los datos y programas desde el almacenamiento permanente.
  • Procesador → Tarjeta gráfica: envía instrucciones para procesar imágenes y videos.
  • Tarjeta gráfica → Pantalla: muestra la imagen procesada al usuario.

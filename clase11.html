Actividad 3: Análisis de rendimiento - Optimización de sistema

Conceptos Claves

1. Cuello de botella

Componente que limita el rendimiento de todo el sistema.

2. Administrador de tareas

Utilidad de Windows para ver el uso de CPU, RAM, disco y red.

3. Memoria virtual

Espacio del HDD o SSD que Windows usa como RAM de emergencia. Es muy lento.

4. Swapping

Proceso de mover datos de la RAM a la memoria virtual por falta de RAM física. Causa lentitud extrema.

Consigna

Usted abre el administrador de tareas en una PC con Windows 11 y observa:

  • CPU: 15%
  • RAM: 97%
  • Disco: 100% activo
  • GPU: 2%

La PC está muy lenta al abrir Chrome con dos pestañas.

  1. Identifique cuál es el cuello de botella principal (CPU, RAM o Disco). Justifique con los porcentajes.
  2. Explique qué es el swapping y por qué el disco está al 100% si la RAM está al 97%.
  3. Proponga tres soluciones ordenadas de menor a mayor costo para resolver el problema.
  4. Complete el informe técnico.

Respuestas

1. Cuello de botella

El principal cuello de botella es la memoria RAM y el disco. La RAM se encuentra al 97% de uso y el disco al 100% de actividad, mientras que el procesador solo trabaja al 15%, por lo que la CPU no es la causa de la lentitud.

2. ¿Qué es el swapping?

El swapping ocurre cuando la memoria RAM está casi llena y el sistema operativo utiliza parte del disco como memoria virtual. Como el disco es mucho más lento que la RAM, la computadora pierde rendimiento y responde con mayor lentitud.

3. Soluciones

  1. Cerrar programas y procesos que no sean necesarios.
  2. Desactivar aplicaciones que se inician junto con Windows.
  3. Agregar más memoria RAM o reemplazar el HDD por un SSD si corresponde.

Informe Técnico

ITEM DETALLE
Problema detectado Rendimiento lento del sistema.
Cuello de botella RAM y Disco.
Causa Uso excesivo de memoria y utilización de memoria virtual.
Solución Optimizar el sistema y ampliar la memoria RAM.
Estado final Equipo funcionando correctamente luego de aplicar las mejoras.

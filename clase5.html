Interfaz Gráfica

La interfaz gráfica (GUI) es el entorno visual que permite al usuario interactuar con el sistema operativo mediante ventanas, iconos, botones y menús, sin necesidad de escribir comandos.

¿Qué es una interfaz gráfica?

Es la parte visual del sistema operativo que facilita la interacción entre el usuario y la computadora mediante elementos gráficos.

¿Qué es desfragmentar?

Es el proceso de reorganizar los archivos almacenados en el disco para mejorar la velocidad y el rendimiento del equipo.

¿Qué es el Panel de Control?

Es una herramienta de Windows que permite modificar la configuración del sistema, administrar dispositivos, programas y cuentas de usuario.

¿Cómo acceder?

  • Desde el menú Inicio.
  • Buscando "Panel de control".
  • Con el comando control en Ejecutar.

Herramientas del Sistema

  • Liberador de espacio.
  • Desfragmentador de discos.
  • Administrador de tareas.
  • Restaurar sistema.
  • Administrador de dispositivos.

Atajos de teclado

  • Ctrl + C → Copiar.
  • Ctrl + V → Pegar.
  • Ctrl + X → Cortar.
  • Ctrl + Z → Deshacer.
  • Alt + Tab → Cambiar de ventana.
  • Windows + E → Explorador de archivos.
